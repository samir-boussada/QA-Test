# Standard Bug / Defect Report Template

| Field | Value / Guidance |
| :--- | :--- |
| **Bug ID** | `BUG-[000]` |
| **Defect Title** | Concise summary in format: `[Module] - [Issue summary when doing X]` |
| **Severity** | Critical / Major / Medium / Low |
| **Priority** | High (P1) / Medium (P2) / Low (P3) |
| **Status** | Open / In Progress / Fixed / Closed / Re-opened |
| **Reporter** | QA Engineer Name |
| **Environment** | OS, Browser version, Screen resolution, App URL |
| **Pre-conditions** | Any prerequisites or user state before triggering the issue |

---

### Description & Steps to Reproduce
1. Navigate to `[URL or Screen]`
2. Perform `[Action 1]`
3. Perform `[Action 2]`
4. Click on `[Element / Button]`

---

### Expected Result
Clear explanation of what was supposed to happen according to requirements.

### Actual Result
Exact description of what happened instead (including error messages or visual defects).

---

### Supporting Evidence & Technical Details
* **Screenshots / Video Link:** `[Attach image or video showing failure]`
* **Network Payload / Response:** `[HTTP status code and response body]`
* **Console Logs:** `[JavaScript errors or stack traces]`

---

### Business Impact & Suggested Fix
* **Impact:** Explanation of how this affects business, user trust, or operations.
* **Suggested Fix / Recommendation:** Technical suggestion for the engineering team.
