# Standard Test Case Template

| Field | Description / Value |
| :--- | :--- |
| **Test Case ID** | `TC_[MODULE]_[000]` |
| **Test Case Title** | Brief, descriptive title of what is being verified |
| **Module / Feature** | Name of the feature or sub-system |
| **Priority** | High (P1) / Medium (P2) / Low (P3) |
| **Test Type** | Functional / Negative / Boundary (BVA) / UI / Security |
| **Pre-conditions** | Prerequisites or system state required before executing |
| **Test Data** | Specific inputs or configurations needed |
| **Test Steps** | 1. Step one<br>2. Step two<br>3. Step three |
| **Expected Result** | What the system should do according to specifications |
| **Actual Result** | What actually occurred during execution |
| **Status** | Pass / Fail / Blocked / Deferred |
| **Linked Defect ID** | Defect reference ID (e.g. `BUG-001`), if failed |
| **Tested By** | Name of the QA Engineer |
| **Execution Date** | YYYY-MM-DD |
